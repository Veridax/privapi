## Mock Server

You can test and simulate the Payments API without any backend setup by using a hosted mock server. This is ideal for quick prototyping, validating request/response formats, and trying out integration flows before the actual services are wired up. The mock server uses the OpenAPI spec to generate dynamic, realistic responses.
